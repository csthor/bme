# UI Design Standard

- Палитра: Friendly Digital — светлая нейтральная база с фиолетовым акцентом.
- Типографика: Inter с системным fallback.
- Стиль: Friendly Rounded с аккуратными карточками и умеренной анимацией.

Повторяемые цвета, spacing, контейнер, радиусы, тени и focus-состояния задаются централизованно в `src/App.css`.
