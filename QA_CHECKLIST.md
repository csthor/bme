# QA Checklist

- [ ] `npm run build` проходит без ошибок.
- [ ] промокоды из админки отображаются на главной;
- [ ] истёкшие промокоды не показываются как актуальные;
- [ ] поиск работает на desktop и mobile;
- [ ] есть видимый `focus-visible`;
- [ ] один H1 и корректная структура H2/H3;
- [ ] robots/sitemap/canonical проверены;
- [ ] поисковые роботы не блокируются сервером;
- [ ] Docker-сборка проверена перед production.
