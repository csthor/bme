# Поиск промокодов магазинов РФ

## Цель

Составить актуальный список магазинов с промокодами. Для каждой записи указать магазин, код, скидку, условия, срок действия, официальный сайт, источник и статус проверки.

## Алгоритм

1. Получить список магазинов от пользователя. Если список не задан, начать с популярных российских магазинов и маркетплейсов.
2. Искать предложения минимум в двух источниках: официальная страница магазина и проверенный агрегатор промокодов.
3. Приоритет источников:
   - официальный сайт или приложение магазина;
   - Rukodi, Picodi, SecretDiscounter;
   - другие агрегаторы — только как дополнительное подтверждение.
4. Отделять настоящий промокод от обычной акции. Акции без поля для ввода кода не записывать как промокод.
5. Если на агрегаторе есть кнопка «Показать код», «Открыть код» или «Получить код», нажать её и сохранить раскрытый код.
6. Если кнопка ведёт в магазин, проверить URL, параметры перехода и текст страницы. Иногда код находится в параметре URL `utm_content` или отображается после перехода.
7. Для проверки применения открыть официальный магазин, выбрать подходящий товар с учётом условий, добавить его в корзину, найти поле промокода, ввести код и нажать «Применить»/«Пересчитать».
8. Не оплачивать заказ и не завершать оформление. Достаточно зафиксировать изменение цены, сообщение об успешном применении или причину отказа.
9. Для кодов, доступных только новым пользователям, приложению, подписке или личному кабинету, явно указать это в комментарии.
10. Не считать код рабочим только потому, что агрегатор пишет «проверено». Рабочим считать код после применения в корзине; если проверить нельзя, использовать статус «заявлен агрегатором».

## Поля результата

| Поле | Что записывать |
|---|---|
| Магазин | Название магазина |
| Официальный сайт | Прямая ссылка |
| Промокод | Точный код с сохранением регистра |
| Выгода | Скидка, бонус или подарок |
| Условия | Минимальная сумма, категории, первый заказ, приложение и т. п. |
| Срок | Дата окончания или «до отмены» |
| Источник | Ссылка на страницу, где найден код |
| Проверено | Дата проверки |
| Статус | Работает / не работает / заявлен агрегатором / скрытый или персональный |
| Комментарий | Ограничения и результат проверки |

## Правила качества

- Не выдумывать код, если сайт показывает только маску вроде `***K2`.
- Не объединять разные магазины или сервисы в одну запись.
- Удалять истёкшие предложения.
- Проверять дату публикации и дату окончания.
- Коды для доставки, ресторана, банка или приложения помечать соответствующей категорией.
- Если код не удалось проверить из-за авторизации, региона, приложения или CAPTCHA, честно указать причину.
- Для больших списков сначала собрать кандидатов, затем проверять их по приоритету: популярность магазина, размер скидки, близость срока окончания и доступность публичного кода.

## Формат ответа

Сначала дать таблицу, затем короткие комментарии по ограничениям. В конце указать, сколько кодов реально проверено, сколько заявлено источниками и сколько не удалось проверить.
