# Layout Standard

## Карта сайта

- `/` — каталог промокодов и акций;
- `/login` — вход администратора;
- `/admin` — управление SEO и промокодами.

## Главная

Header → Hero → Categories → Stores → Promo codes → Benefits → Footer.

Повторно используемые блоки: Header, Footer, Search, Card, Badge, Button, promo card, carousel.

Фиктивные ссылки «Блог», «Избранное» и «Регистрация» пока не считаются реализованными функциями.
