# Tech Stack Standard

- Frontend: React 18 + Vite.
- Backend: минимальный Express API.
- Storage: JSON-файл для текущего MVP; публичные данные читаются через API.
- Routing: React Router.
- Styling: единые CSS tokens.
- Deployment: Docker, Nginx, HTTPS.
- Package manager: npm.

JSON-хранилище подходит для небольшого каталога. При росте проекта потребуется база данных или CMS.
