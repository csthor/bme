# Импорт Kupon4UK

## Описание

Файл для целевого загрузчика: `kupon4uk-promos-import.json`.

- 27 промокодов, 11 магазинов.
- `status: pending` — записи готовы к модерации, но не публикуются автоматически.
- `verification_status: manual_review` — код раскрыт кнопкой, но не проверен оформлением заказа.
- `verification_status: unverified` — код заявлен источником, проверка в корзине не выполнена.
- Иконки указаны с официальных доменов как favicon fallback; для публикации загрузчик должен заменить их на проверенный официальный SVG/PNG и сохранить SHA-256.
- Текущий SEO endpoint не сохраняет эти поля. Нужен `POST /api/import/promos` с авторизацией администратора.

## Минимальная проверка перед публикацией

1. Источник доступен
2. Код вводится в корзине
3. Условия совпадают
4. Срок не истёк
5. Иконка имеет статус `valid`
