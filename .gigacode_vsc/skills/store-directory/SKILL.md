# Справочник магазинов и сервисов РФ

## Описание

Каталог популярных российских магазинов и сервисов, сгруппированных по категориям. Используется как справочник при поиске промокодов и формировании списка магазинов.

## Категории и магазины

| Название | Описание |
|---|---|
| М.Видео | Крупнейшая сеть магазинов цифровой и бытовой техники в России |
| Эльдорадо | Сеть магазинов электроники и бытовой техники |
| DNS | Интернет-магазин компьютерной техники и электроники |
| Ситилинк | Сеть магазинов электроники с пунктами выдачи по всей России |
| Яндекс.Маркет | Маркетплейс электроники и гаджетов от Яндекса |
| СберМегаМаркет | Маркетплейс электроники от экосистемы Сбера |
