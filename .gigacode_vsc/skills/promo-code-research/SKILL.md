# Поиск промокодов магазинов РФ

## Цель

Составить актуальный список магазинов с промокодами. Главный результат — не список источников, а найденные промокоды к каждому магазину, который прислал пользователь. Для каждой записи указать магазин, код, скидку, условия, срок действия, официальный сайт, источник и статус проверки.

## Обязательный результат

- Нельзя завершать работу только перечнем найденных сайтов или общими акциями.
- Каждый магазин из пользовательского списка должен присутствовать в итоговом результате.
- Для каждого магазина нужно найти и записать минимум один промокод, если он существует.
- Если после полного поиска промокод не найден, это нужно явно указать: «Публичный промокод не найден», с кратким описанием проверенных источников и причины.
- Коды, скрытые кнопкой, popup, URL, буфером обмена, приложением или Telegram, нужно раскрыть и записать полностью, если доступ не требует личных данных пользователя.
- Итоговая таблица должна позволять сразу использовать промокод: магазин, ссылка, код, краткое описание, выгода, условия и способ применения.
- Перед завершением сверить количество магазинов пользователя с количеством строк результата и отдельно указать пропуски.

## Приоритет источников

Искать источники в таком порядке:

1. Официальный сайт магазина: разделы «Промокоды», «Акции», баннеры, корзина, программа лояльности.
2. Официальное приложение магазина: баннеры, push-предложения, купоны, разделы «Выгода» и «Промокоды».
3. Официальные Telegram-каналы, боты, VK и email-рассылки магазина.
4. Официальные страницы бренда и правила рекламных акций.
5. Проверенные агрегаторы: Rukodi, Picodi, SecretDiscounter и другие каталоги.
6. Остальные сайты, форумы и соцсети — только как дополнительный источник, с обязательной пометкой о низкой надёжности.

Если код найден в нескольких местах, сохранять все источники, но главным считать источник с более высоким приоритетом.

## Алгоритм

1. Получить список магазинов от пользователя. Если список не задан, начать с популярных российских магазинов и маркетплейсов.
2. Искать предложения минимум в двух источниках: официальная страница магазина и проверенный агрегатор промокодов.
3. Приоритет источников:
    - официальный сайт или приложение магазина;
    - Rukodi, Picodi, SecretDiscounter;
    - другие агрегаторы — только как дополнительное подтверждение.
4. Отделять настоящий промокод от обычной акции. Акции без поля для ввода кода не записывать как промокод.
5. Если на агрегаторе есть кнопка «Показать код», «Открыть код» или «Получить код», обязательно нажать её. Частично отображаемый код вроде `***6D` нельзя записывать как результат: нужно перейти по кнопке, проверить URL, параметры перехода, буфер обмена, открывшуюся страницу или всплывающее окно и извлечь полный код.
6. Если кнопка ведёт в магазин, проверить URL, параметры перехода и текст страницы. Иногда код находится в параметре URL `utm_content` или отображается после перехода.
7. Для проверки применения открыть официальный магазин, выбрать подходящий товар с учётом условий, добавить его в корзину, найти поле промокода, ввести код и нажать «Применить»/«Пересчитать».
8. Не оплачивать заказ и не завершать оформление. Достаточно зафиксировать изменение цены, сообщение об успешном применении или причину отказа.
9. Для кодов, доступных только новым пользователям, приложению, подписке или личному кабинету, явно указать это в комментарии.
10. Не считать код рабочим только потому, что агрегатор пишет «проверено». Рабочим считать код после применения в корзине; если проверить нельзя, использовать статус «заявлен агрегатором».
11. Для каждого магазина определить рубрику: маркетплейс, одежда и обувь, электроника, красота и здоровье, продукты, доставка еды, зоотовары, книги, дом и ремонт, путешествия, услуги, развлечения или другое.
12. Зафиксировать сложность поиска: лёгкая — код найден открыто; средняя — нужно было открыть карточку, popup или перейти по ссылке; сложная — нужен аккаунт, приложение, подписка, регион или ручная проверка корзины.

## Поля результата

| Поле | Что записывать |
|---|---|
| Магазин | Название магазина |
| Рубрика | Категория магазина |
| Ссылка на магазин | Прямая ссылка на официальный сайт или приложение |
| Официальный сайт | Прямая ссылка |
| Промокод | Точный код с сохранением регистра |
| Короткое описание | Одно короткое предложение: что даёт промо и кому подходит |
| Выгода | Скидка, бонус или подарок |
| Как использовать | Куда вводить код: корзина, приложение, поле «Промокод», ссылка или подписка |
| Условия | Минимальная сумма, категории, первый заказ, приложение и т. п. |
| Срок | Дата окончания или «до отмены» |
| Источник | Все страницы, где найден код, с указанием приоритета источника |
| Как найден | Что сделано: поиск, открытие карточки, нажатие кнопки, переход, проверка popup/URL/буфера обмена |
| Сложность поиска | Лёгкая / средняя / сложная и короткая причина |
| Проверено | Дата проверки |
| Статус | Работает / не работает / заявлен агрегатором / скрытый или персональный |
| Комментарий | Ограничения и результат проверки |

## Правила качества

- Не оставлять код в частично скрытом виде вроде `***K2`: сначала нажать кнопку раскрытия и проверить все доступные источники полного значения. Если после этого полный код действительно недоступен, записать «код не раскрыт» и указать, что именно было проверено.
- Не объединять разные магазины или сервисы в одну запись.
- Удалять истёкшие предложения.
- Проверять дату публикации и дату окончания.
- Коды для доставки, ресторана, банка или приложения помечать соответствующей категорией.
- Если код не удалось проверить из-за авторизации, региона, приложения или CAPTCHA, честно указать причину.
- Для больших списков сначала собрать кандидатов, затем проверять их по приоритету: популярность магазина, размер скидки, близость срока окончания и доступность публичного кода.
- Для каждого найденного промокода обязательно добавлять короткое понятное описание без рекламных формулировок.
- Каждый результат должен содержать магазин, ссылку, рубрику, все найденные коды, краткое описание, выгоду, способ использования, условия, срок, источники, способ поиска и сложность поиска.
- Для каждого магазина обязательно искать и сохранять официальную иконку: сначала SVG с официального сайта, затем PNG; если их нет — официальный favicon. Иконку загружать в карточку магазина вместе с промокодом.
- Для иконки сохранять URL источника, формат, размеры и способ получения. Не брать логотипы со случайных сайтов, если доступен официальный источник.
- Текст описания и инструкции держать короткими и понятными: обычно 1–2 предложения на поле.
- Не смешивать официальный источник, приложение, Telegram и агрегатор: указывать их отдельными источниками с приоритетом.

## Формат ответа

Сначала дать таблицу, затем короткие комментарии по ограничениям. В конце указать, сколько кодов реально проверено, сколько заявлено источниками и сколько не удалось проверить.
