# Project Brief

Kupon4UK — русскоязычный каталог актуальных промокодов и скидок. Главная задача — привести пользователя к рабочему предложению и дать возможность быстро скопировать код.

## MVP

- главная страница каталога;
- поиск по магазинам;
- карточки промокодов и акций;
- защищённая админ-панель для обновления SEO и промокодов;
- адаптивная версия;
- базовые SEO-метаданные и structured data;
- Docker/Nginx deployment.

## Вне текущего scope

- регистрация пользователей и личный кабинет;
- блог и полноценные страницы магазинов;
- партнёрская аналитика;
- автоматический импорт промокодов из внешних API.

## Ограничения

- рабочая ветка: `develop`;
- крупные изменения — в отдельной ветке;
- промокоды должны иметь единый источник данных.
